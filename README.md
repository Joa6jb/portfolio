# Portfolio · Joaquín Fernandez

Portfolio personal: desarrollador web autodidacta, AI Engineer, soporte técnico en BEAN y estudiante de Licenciatura en Sistemas (UNLa).

🌐 **Sitio:** https://joaquinfernandez-dev.web.app

## Tecnologías
- HTML5, CSS3 y JavaScript (sin frameworks)
- Firebase Hosting
- GitHub Actions para publicar automáticamente

## Estructura
```
index.html      → la página
404.html        → página de error
favicon.svg     → ícono
assets/         → imágenes y capturas
firebase.json   → configuración del hosting
.github/        → publicación automática
```

## Cómo actualizar la página
Cada cambio que se sube a la rama `main` se publica solo en Firebase en 1-2 minutos.

```bash
git add .
git commit -m "Describí el cambio"
git push
```

El progreso se ve en la pestaña **Actions** del repositorio.
